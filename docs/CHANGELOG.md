# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

Versions correspond to releases of the compiled volumes
(`<YEAR>_ARLIZ_<Title>_Volume_<N>.pdf`), not to individual chapters --
each volume continues to evolve as a "living edition" between tagged releases.

## [Unreleased]

### Added
- Initial public structure for the three-volume edition: *Zero to Bit*,
  *Silicon Horizon*, and *Array Odyssey*.

## [0.1.0] - 2026-06-15

### Added
- First tagged living-edition snapshot of Arliz.
- Volume I -- Zero to Bit: representation, encoding, and bit-level foundations.
- Volume II -- Silicon Horizon: hardware and architecture (in progress).
- Volume III -- Array Odyssey: arrays, algorithms, and applications (in progress).
- Build pipeline producing `<YEAR>_ARLIZ_<Title>_Volume_<N>.{tex,pdf}` per volume.
